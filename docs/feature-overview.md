## 1. 产品愿景与品类规划

**Goods-Tools** 旨在为同人创作者、商谷画师及周边爱好者提供一站式、开箱即用的周边打样排版与工艺模拟服务。在送厂印制前，直观检查各品类的排版构图、裁切/包边安全区，并预览真实的工艺质感。

## 2. 核心模块：马口铁吧唧打样台（已就绪）

### 2.1 用户操作流

```text
打开工作台
  -> 选择形状（圆形/方形）和成品尺寸（25/32/44/58/75mm）
  -> 上传画稿（JPG / PNG / WebP，支持拖拽）
  -> 拖动平移排版或在侧边栏调整缩放
  -> 一键构图锁定，开启 360° 拟真环形展示动画
  -> 选择闪底层与表面覆膜层（支持双闪复合）
  -> 使用顶部比例尺放大查看微距工艺细节
  -> 模态弹窗确认并导出 300 DPI 制作原图或 1080px 效果图
```

### 2.2 图片排版与交互控制
- [x] 支持本地文件选择与拖拽上传，支持 JPG、PNG、WebP，最大支持 15MB，长边自动限制为 2048px 保证性能；
- [x] **构图锁定 (Composition Lock)**：顶部工具栏提供一键锁定，锁定后禁用图片拖动排版；未锁定时支持拖拽平移排版；
- [x] **视口比例尺 (Viewport Zoom)**：顶部工具栏集成 `[ − ] [ 100% ] [ + ] [ ⛶ 适应 ]` 控件组（50%~250%），无损放大查看工艺微距细节；
- [x] **防误触漫游设计**：彻底解除滚轮对视口/图片缩放的意外劫持；放大吧唧后，滚轮与触控板可自由平移浏览大图细节；
- [x] **移动端专属适配**：顶部工具栏在小屏设备下自适应为双层对称控制条，单手操作更加自如。

### 2.3 真实工艺着色体系（7 闪底 + 6 覆膜）
- [x] **底纸材质层（闪底，共 7 款）**：
  - `无闪底 (纯白卡)`：标准铜版白卡纸底
  - `细银闪`：微米级高密度银白微晶颗粒，细腻微光
  - `银葱`：六边形大反光亮片排列，闪烁感强烈
  - `拉丝银葱`：单向金属横向拉丝纹理叠加银闪微粒
  - `幻彩白沙`：极细偏光白沙晶粒，多向折射柔和彩光
  - `细金闪`：奢华香槟金与流金微粒，暖色星芒
  - `珠光底`：丝缎般的母贝偏光漫反射
- [x] **表面光学保护膜（覆膜，共 6 款）**：
  - `无膜`：基础裸面
  - `高透亮膜`：微弧面双层高反差窗光反射带
  - `丝绒哑膜`：消光雾面触感与柔和漫反射
  - `素面镭射膜`：基于物理色散波长的连续彩虹光谱流转
  - `碎玻璃镭射膜`：程序化多面水晶晶格，各晶面随视角独立计算色相与反光折射
  - `十字星芒膜`：正交 90° 十字衍射光栅耀斑
- [x] **双闪复合体系**：闪底层与覆膜层分层独立计算与叠加，底纸闪粉穿透薄膜折射出彩虹星芒，同时保护原画暗部对比度；
- [x] **360° 拟真环形展示动画**：模拟人手持吧唧在光源下做 360° 连续圆周倾斜展示，高光、折射光谱与阴影沿真实物理空间轨迹丝滑转动。

### 2.5 双导出规范
- **效果预览图**：导出 1080×1080px PNG，包含金属边缘暗影、立体投影、背景与当前工艺模拟，适合社交平台预览分享；
- **制作原图**：模态弹窗核对规格后导出 300 DPI 无损 PNG，仅包含完整形状范围内的排版画稿，不含特效与参考线，写入 300 DPI 元数据供工厂印刷使用。

## 3. 生产与职责边界

- **本工具职责**：负责画稿排版、工艺模拟预览、安全区校对与符合分辨率标准的制作原图导出；
- **印厂生产职责**：负责实际套用专用刀模、拼版印刷、覆膜冲压与成品组装；
- **用户建议**：不同工厂的模具与包边公差略有差异，建议将导出的制作原图与标称尺寸一同提供给印厂确认。
