# 谷子Tools 产品规格 v1.1

> 状态: 首版实现基线  
> 定位: 用户侧的吧唧成品预览和原图导出工具  
> 数据原则: 图片只在浏览器本地处理, 不上传用户图片

## 1. 产品边界

- 让用户知道图片做成吧唧后, 正面会看到什么.
- 让用户知道成品尺寸、完整图片尺寸和包边区域.
- 让用户把调整好的完整形状原图交给商家继续制作.
- 不把商家刀模、颜色管理和生产流程作为首版用户功能.
- 不承诺屏幕颜色、膜材反光和不同工厂的包边误差完全一致.

首版支持圆形和方形吧唧. 预览使用一套通用包边参考值, 用于帮助用户理解构图, 不代表任何特定商家的生产标准.

## 2. 用户流程

```text
打开工作台
  -> 选择形状和成品尺寸
  -> 上传 JPG / PNG / WebP
  -> 拖动和缩放图片
  -> 查看成品效果或完整图片范围
  -> 选择闪底(无 / 银闪)和覆膜(无 / 亮膜 / 素面镭射)
  -> 导出效果预览图或制作原图
```

## 3. 首版功能

### 3.1 图片输入与编辑

- [x] 支持文件选择和拖放上传.
- [x] 支持 JPG、PNG 和 WebP.
- [x] 拒绝非图片文件和超过 15MB 的文件.
- [x] 将工作图最长边限制为 2048px.
- [x] 图片只保留在当前页面内存中.
- [x] 支持拖动、滚轮缩放、滑杆缩放、双指缩放和重置.
- [x] 始终保证完整图片范围被用户图片覆盖.

### 3.2 成品效果

- [x] 绘制对应形状的图案、边缘弯曲暗影和投影.
- [x] 圆形使用径向渐变阴影, 方形使用四边线性渐变和角落径向暗化, 模拟纸面弯曲到背面的效果.
- [x] 工艺拆分为闪底层和覆膜层, 用户独立组合.
- [x] 闪底层: 无闪底、银闪(细闪粉粒子, 随晃动闪烁).
- [x] 覆膜层: 无膜、亮膜(高光反射)、素面镭射(整面彩虹光谱).
- [x] 银闪 + 素面镭射 = 双闪, 两层效果叠加.
- [x] 所有工艺默认静止, 可切换动态预览模拟吧唧晃动.
- [x] 切换成品尺寸时同步调整吧唧本体的预览比例和图案映射.
- [x] 无工艺只保留边缘弯曲暗影和投影, 不叠加表面光晕.
- [x] 素面镭射使用 conic 彩虹分布, 覆盖 0-180 和 330-360 色相范围, 随视角变化色相, 模拟真实镭射膜光泽.
- [x] 支持暂停动画并遵循系统减少动态效果设置.
- [x] 使用默认样稿帮助用户理解编辑结果.

### 3.3 尺寸与包边说明

用户只选择形状和成品尺寸, 不填写商家生产参数. 系统自动展示四个值:

| 名称 | 含义 |
|---|---|
| 成品可见尺寸 | 做成吧唧后, 正面主要能看到的尺寸 |
| 完整图片尺寸 | 交给商家的完整原图尺寸, 包含外圈包边区域 |
| 每侧包边区 | 从可见边缘向外延伸, 最终被压入或卷入内部的区域 |
| 建议安全区 | 文字、人脸和主体应尽量留在其中的区域 |

圆形尺寸表示直径, 方形尺寸表示边长. 完整图片始终输出为与选择尺寸对应的正方形画布, 透明区域由当前形状裁切.

当前通用参考尺寸:

| 成品标称尺寸 | 完整图片尺寸 | 每侧包边区 | 建议安全区 |
|---:|---:|---:|---:|
| 25mm | 31mm | 3mm | 23mm |
| 32mm | 38mm | 3mm | 30mm |
| 44mm | 52mm | 4mm | 42mm |
| 58mm | 70mm | 6mm | 54mm |
| 75mm | 87mm | 6mm | 71mm |

这些数值是预览参考, 不叫作“商家模板”. 如果用户拿到商家的专用刀模, 应以商家文件为最终生产依据, 但首版不要求用户把刀模参数录入工具.

### 3.4 双视图

- [x] 成品效果: 显示正面可见的吧唧效果、边缘弯曲暗影和投影.
- [x] 完整图片范围: 按当前形状显示完整图片、可见区、包边区和安全区.
- [x] 用颜色和线型区分区域.
- [x] 参考线只显示在编辑画布, 不写入制作原图.

### 3.5 双导出

#### 效果预览图

- [x] 导出 1080x1080 PNG.
- [x] 包含边缘弯曲暗影、投影、背景和当前工艺模拟.
- [x] 用于预览和分享, 不作为打印原图.

#### 制作原图

- [x] 导出完整图片尺寸对应的正方形 PNG.
- [x] 按 300 DPI 计算像素尺寸.
- [x] 只在当前完整形状范围内输出调整后的原图.
- [x] 形状外保持透明.
- [x] 不包含外壳、阴影、高光、镭射效果和参考线.
- [x] 文件名包含成品尺寸、完整图片尺寸和 DPI.
- [x] 写入 300 DPI PNG 元数据, 便于支持物理尺寸的图像软件按原尺寸打开.

像素尺寸使用以下公式:

$$
\text{pixelSize}=\operatorname{round}\left(\frac{\text{完整图片尺寸(mm)}}{25.4}\times300\right)
$$

例如 58mm 成品的默认完整图片尺寸为 70mm, 制作原图为 827x827px.

## 4. 工作台结构

```text
桌面端
┌────────────────────────────┬──────────────────┐
│                            │ 图片              │
│      成品 / 完整图片画布     │ 工艺              │
│                            │ 成品尺寸          │
│                            │ 导出              │
└────────────────────────────┴──────────────────┘

移动端
┌────────────────────────────┐
│      成品 / 完整图片画布     │
├────────────────────────────┤
│ 图片 / 工艺 / 成品尺寸       │
├────────────────────────────┤
│ 效果图 / 制作原图             │
└────────────────────────────┘
```

## 6. 延后功能

- 添加本地图库和方案历史.
- 添加长方形、盾形和其他异形吧唧.
- 添加金闪、珠光底等更多闪底选择.
- 添加哑光膜、碎冰镭射、方格镭射等更多覆膜选择.
- 支持用户导入商家刀模作为高级校准参考, 但不把它做成首版必需流程.
- 在 Web 使用数据证明需求后开发微信小程序.

## 7. 生产边界

- 本工具负责构图预览和完整原图导出.
- 商家负责套用自己的刀模、排版、色彩转换和实际生产.
- 不同工厂的包边宽度和裁切误差可能不同.
- 用户应把制作原图和成品尺寸一并交给商家确认.
