# 谷子Tools 产品规格 v1.1

> 状态: 首版实现基线  
> 定位: 用户侧的吧唧成品预览和原图导出工具  
> 数据原则: 图片只在浏览器本地处理, 不上传用户图片

## 1. 产品边界

- 让用户知道图片做成吧唧后, 正面会看到什么.
- 让用户知道成品尺寸、完整图片尺寸和包边区域.
- 让用户把调整好的完整形状原图交给商家继续制作.
- 不把商家刀模、颜色管理和生产流程作为首版用户功能.
- 不承诺屏幕颜色、膜材反光和不同工厂的包边误差完全一致.

首版支持圆形和方形吧唧. 预览使用一套通用包边参考值, 用于帮助用户理解构图, 不代表任何特定商家的生产标准.

## 2. 用户流程

```text
打开工作台
  -> 选择形状和成品尺寸
  -> 上传 JPG / PNG / WebP
  -> 拖动和缩放图片
  -> 查看成品效果或完整图片范围
  -> 选择闪底(无 / 银闪)和覆膜(无 / 亮膜 / 素面镭射)
  -> 导出效果预览图或制作原图
```

## 3. 首版功能

### 3.1 图片输入、排版与视口交互

- [x] 支持文件选择和拖放上传.
- [x] 支持 JPG、PNG 和 WebP.
- [x] 拒绝非图片文件和超过 15MB 的文件.
- [x] 将工作图最长边限制为 2048px.
- [x] 图片只保留在当前页面内存中.
- [x] **构图锁定 (Composition Lock)**：顶部工具栏提供一键锁定，锁定后禁用图片拖动排版；未锁定时支持拖拽平移排版.
- [x] **视口比例尺 (Viewport Zoom)**：顶部工具栏集成 `[ − ] [ 100% ] [ + ] [ ⛶ 适应 ]` 控件组（50%~250%），无损放大查看工艺微距细节（微米级闪粉、十字星芒与包边轮廓），不改变实际制作原图.
- [x] **绝对防误触设计**：彻底解除滚轮与手势对图片/视口缩放的意外触发；放大吧唧后滚轮可自由上下平移浏览大图细节.

### 3.2 成品效果与主流工艺系统

- [x] 绘制对应形状的图案、微凸穹顶环境光、冲压金属包边高光轮廓线、包边弯曲暗影与分层真实投影.
- [x] 圆形使用径向渐变阴影与高光环，方形使用四边线性渐变与圆角高光倒角，还原马口铁徽章实体质感.
- [x] 工艺拆分为闪底层和覆膜层，支持用户自由独立组合与双闪联动.
- [x] **主流闪底层（基材/底纸材质，共 7 款）**：
  - `无闪底 (纯白卡)`：基础铜版白卡纸基底
  - `细银闪`：**【细腻微光】** 微米级高密度极细银白微晶，迎光激发轻柔微芒
  - `银葱`：**【谷圈经典大亮片】** 六边形大反光亮片与强反光金属晶片，闪烁感强烈
  - `拉丝银葱 (金属拉丝)`：**【机甲/帅气风】** 单向金属拉丝纹理 + 银闪微粒
  - `幻彩白沙 (细沙偏光)`：**【柔和唯美】** 极细微晶白沙，随视角带有柔和多向偏光
  - `细金闪 (金葱底)`：**【华丽限定】** 奢华香槟金与流金微粒，暖色星芒耀斑
  - `珠光底 (贝母纸)`：**【温润典雅】** 丝缎般的粉青双色母贝反光
- [x] **主流覆膜层（表面光学保护膜，共 6 款）**：
  - `无膜 (裸面)`：纸质基础
  - `高透亮膜 (光面)`：**【基础标配】** 清透微弧面双层窗光反射带滑动
  - `丝绒哑膜 (磨砂)`：**【主流高级】** 消光天鹅绒触感，微磨砂质感与柔和漫反射
  - `素面镭射膜 (彩虹)`：**【经典全息】** 基于物理色散波长的连续彩虹光谱流转与高光聚焦点
  - `碎玻璃镭射膜 (碎冰)`：**【谷圈爆款第一】** 程序化多面水晶晶格，各晶面随视角独立计算色相与反光折射
  - `十字星芒膜 (十字)`：**【璀璨耀斑】** 规则排列的十字星全息光栅，随角度闪耀
- [x] **双闪复合体系**：闪底层 + 覆膜层自由组合，闪粉穿透薄膜折射出彩虹星芒，同时精准保护原画暗部与对比度不发灰发白.
- [x] **拟真 360° 环形展示动画**：模拟人手持吧唧在光源下做 360° 连续圆周环形轻摇把玩，高光、折射光谱与阴影沿真实物理空间轨迹丝滑转动.
- [x] 切换成品尺寸时同步按物理比例调整吧唧本体在视口中的尺寸与图案映射.
- [x] 支持暂停动画并严格遵循操作系统“减少动态效果”设置.
- [x] 内置默认样稿帮助用户即时理解编辑和工艺效果.

### 3.3 尺寸与包边说明

用户只选择形状和成品尺寸, 不填写商家生产参数. 系统自动展示四个值:

| 名称 | 含义 |
|---|---|
| 成品可见尺寸 | 做成吧唧后, 正面主要能看到的尺寸 |
| 完整图片尺寸 | 交给商家的完整原图尺寸, 包含外圈包边区域 |
| 每侧包边区 | 从可见边缘向外延伸, 最终被压入或卷入内部的区域 |
| 建议安全区 | 文字、人脸和主体应尽量留在其中的区域 |

圆形尺寸表示直径, 方形尺寸表示边长. 完整图片始终输出为与选择尺寸对应的正方形画布, 透明区域由当前形状裁切.

当前通用参考尺寸:

| 成品标称尺寸 | 完整图片尺寸 | 每侧包边区 | 建议安全区 |
|---:|---:|---:|---:|
| 25mm | 31mm | 3mm | 23mm |
| 32mm | 38mm | 3mm | 30mm |
| 44mm | 52mm | 4mm | 42mm |
| 58mm | 70mm | 6mm | 54mm |
| 75mm | 87mm | 6mm | 71mm |

这些数值是预览参考, 不叫作“商家模板”. 如果用户拿到商家的专用刀模, 应以商家文件为最终生产依据, 但首版不要求用户把刀模参数录入工具.

### 3.4 双视图

- [x] 成品效果: 显示正面可见的吧唧效果、边缘弯曲暗影和投影.
- [x] 完整图片范围: 按当前形状显示完整图片、可见区、包边区和安全区.
- [x] 用颜色和线型区分区域.
- [x] 参考线只显示在编辑画布, 不写入制作原图.

### 3.5 双导出

#### 效果预览图

- [x] 导出 1080x1080 PNG.
- [x] 包含边缘弯曲暗影、投影、背景和当前工艺模拟.
- [x] 用于预览和分享, 不作为打印原图.

#### 制作原图

- [x] 导出完整图片尺寸对应的正方形 PNG.
- [x] 按 300 DPI 计算像素尺寸.
- [x] 只在当前完整形状范围内输出调整后的原图.
- [x] 形状外保持透明.
- [x] 不包含外壳、阴影、高光、镭射效果和参考线.
- [x] 文件名包含成品尺寸、完整图片尺寸和 DPI.
- [x] 写入 300 DPI PNG 元数据, 便于支持物理尺寸的图像软件按原尺寸打开.

像素尺寸使用以下公式:

$$
\text{pixelSize}=\operatorname{round}\left(\frac{\text{完整图片尺寸(mm)}}{25.4}\times300\right)
$$

例如 58mm 成品的默认完整图片尺寸为 70mm, 制作原图为 827x827px.

## 6. 延后功能

- 添加本地图库和方案历史.
- 添加长方形、盾形和其他异形吧唧.
- 添加金闪、珠光底等更多闪底选择.
- 添加哑光膜、碎冰镭射、方格镭射等更多覆膜选择.
- 支持用户导入商家刀模作为高级校准参考, 但不把它做成首版必需流程.
- 在 Web 使用数据证明需求后开发微信小程序.

## 7. 生产边界

- 本工具负责构图预览和完整原图导出.
- 商家负责套用自己的刀模、排版、色彩转换和实际生产.
- 不同工厂的包边宽度和裁切误差可能不同.
- 用户应把制作原图和成品尺寸一并交给商家确认.
