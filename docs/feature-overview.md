# 谷子Tools 产品规格 v1.1

> 状态: 首版实现基线  
> 定位: 用户侧的吧唧成品预览和原图导出工具  
> 数据原则: 图片只在浏览器本地处理, 不上传用户图片

## 1. 产品边界

- 让用户知道图片做成吧唧后, 正面会看到什么.
- 让用户知道成品直径、完整图片直径和包边区域.
- 让用户把调整好的完整圆形原图交给商家继续制作.
- 不把商家刀模、颜色管理和生产流程作为首版用户功能.
- 不承诺屏幕颜色、膜材反光和不同工厂的包边误差完全一致.

首版支持圆形吧唧. 预览使用一套通用包边参考值, 用于帮助用户理解构图, 不代表任何特定商家的生产标准.

## 2. 用户流程

```text
打开工作台
  -> 选择成品尺寸
  -> 上传 JPG / PNG / WebP
  -> 拖动和缩放图片
  -> 查看成品效果或完整图片范围
  -> 切换无工艺 / 镭射膜
  -> 导出效果预览图或制作原图
```

## 3. 首版功能

### 3.1 图片输入与编辑

- [x] 支持文件选择和拖放上传.
- [x] 支持 JPG、PNG 和 WebP.
- [x] 拒绝非图片文件和超过 15MB 的文件.
- [x] 将工作图最长边限制为 2048px.
- [x] 图片只保留在当前页面内存中.
- [x] 支持拖动、滚轮缩放、滑杆缩放、双指缩放和重置.
- [x] 始终保证完整图片范围被用户图片覆盖.

### 3.2 成品效果

- [x] 绘制圆形图案、金属壳边、投影和高光.
- [x] 提供无工艺和镭射膜两种效果.
- [x] 切换成品尺寸时同步调整吧唧本体的预览比例和图案映射.
- [x] 无工艺只保留基础金属外壳和边缘高光, 不叠加表面光晕.
- [x] 镭射膜使用低对比度棱彩膜层和细密干涉纹理, 避免大面积彩虹滤镜感.
- [x] 支持暂停动画并遵循系统减少动态效果设置.
- [x] 使用默认样稿帮助用户理解编辑结果.

### 3.3 尺寸与包边说明

用户只选择成品尺寸, 不填写商家生产参数. 系统自动展示四个值:

| 名称 | 含义 |
|---|---|
| 成品可见直径 | 做成吧唧后, 正面主要能看到的直径 |
| 完整图片直径 | 交给商家的圆形原图直径, 包含外圈包边区域 |
| 每侧包边区 | 从可见边缘向外延伸, 最终被压入或卷入内部的区域 |
| 建议安全区 | 文字、人脸和主体应尽量留在其中的区域 |

当前通用参考尺寸:

| 成品尺寸 | 完整图片尺寸 | 每侧包边区 | 建议安全区 |
|---:|---:|---:|---:|
| 25mm | 31mm | 3mm | 23mm |
| 32mm | 38mm | 3mm | 30mm |
| 44mm | 52mm | 4mm | 42mm |
| 58mm | 70mm | 6mm | 54mm |
| 75mm | 87mm | 6mm | 71mm |

这些数值是预览参考, 不叫作“商家模板”. 如果用户拿到商家的专用刀模, 应以商家文件为最终生产依据, 但首版不要求用户把刀模参数录入工具.

### 3.4 双视图

- [x] 成品效果: 只显示正面可见的吧唧效果.
- [x] 完整图片范围: 显示完整图片、可见区、包边区和安全区.
- [x] 用颜色和线型区分区域.
- [x] 参考线只显示在编辑画布, 不写入制作原图.

### 3.5 双导出

#### 效果预览图

- [x] 导出 1080x1080 PNG.
- [x] 包含吧唧外壳、阴影、背景和当前工艺模拟.
- [x] 用于预览和分享, 不作为打印原图.

#### 制作原图

- [x] 导出完整图片直径对应的正方形 PNG.
- [x] 按 300 DPI 计算像素尺寸.
- [x] 只在完整圆形范围内输出调整后的原图.
- [x] 圆外保持透明.
- [x] 不包含外壳、阴影、高光、镭射效果和参考线.
- [x] 文件名包含成品尺寸、完整图片尺寸和 DPI.
- [x] 写入 300 DPI PNG 元数据, 便于支持物理尺寸的图像软件按原尺寸打开.

像素尺寸使用以下公式:

$$
\text{pixelSize}=\operatorname{round}\left(\frac{\text{完整图片直径(mm)}}{25.4}\times300\right)
$$

例如 58mm 成品的默认完整图片直径为 70mm, 制作原图为 827x827px.

```text
桌面端
┌────────────────────────────┬──────────────────┐
│                            │ 图片              │

│                            │ 成品尺寸          │

┌────────────────────────────┐
│      成品 / 完整图片画布     │

├────────────────────────────┤
│ 效果图 / 制作原图             │
└────────────────────────────┘
```

## 6. 延后功能

- 添加本地图库和方案历史.
- 添加更多形状, 如方形、圆角方形和异形.
- 添加亮膜、哑光和星光工艺.
- 支持用户导入商家刀模作为高级校准参考, 但不把它做成首版必需流程.
- 在 Web 使用数据证明需求后开发微信小程序.

## 7. 生产边界

- 本工具负责构图预览和完整原图导出.
- 商家负责套用自己的刀模、排版、色彩转换和实际生产.
- 不同工厂的包边宽度和裁切误差可能不同.
- 用户应把制作原图和成品尺寸一并交给商家确认.
